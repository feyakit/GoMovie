**项目定位**：`GoMovie`（当前版本 `1.0.0+117`）是一款基于 Flutter + Go 核心构建的多端影视播放器。应用本体与站源模块解耦，内置 14 个站源模块，并原生支持 **饭太硬 / TVBox 订阅源** 与 **夸克网盘分享直链播放**。

> [!IMPORTANT]
> **非商用声明**：本项目仅用于个人学习与技术研究，**严禁用于任何商业用途或变相盈利行为**，作者不提供任何商业授权或付费服务。详见 [免责声明与使用规范](#免责声明与使用规范)。

## 核心功能

### 视觉与多端适配

- **赤金品牌主题（Option B）**：默认采用「炭黑 `#0A0A0C` × 赤金 `#FF2E54 → #FF9E2C`」深色影院视觉体系，支持浅色 / 深色 / 跟随系统、纯黑 OLED 模式、系统取色以及 7 套预设色板（赤金、暖橙、玫红、琥珀、青绿、海蓝、蓝紫）。
- **自适应界面模式**：支持自动识别、手机、平板、窗口（桌面端）与电视模式。手机采用底栏导航，平板/电脑采用可收起侧栏，电视采用顶部 Tab 并强制横屏焦点导航。

### 发现、搜索与订阅

- **多站源浏览**：发现页顶部直接切换站源；支持推荐 / 全部 / 榜单 / 题材分类，支持封面模糊隐私保护（可设启动自动模糊限制级或全部封面）。
- **快速搜索**：支持当前站源搜索、最近搜索记录与输入联想。
- **粘贴网盘链接**：发现页站源栏提供「粘贴网盘链接」快捷入口，粘贴夸克分享链接即可直接打开剧集详情页播放。

### 播放体验

| 设备 | 交互与播控体验 |
| --- | --- |
| 桌面端（Windows / macOS） | 左侧视频 + 右侧选集栏，支持宽屏与全屏；悬停显示清晰度、倍速与音量；支持空格、Enter、方向键、Page Up/Down、M 静音等快捷键 |
| 手机端（Android / iOS） | 竖屏短剧沉浸上下翻页切集；左右滑快进/快退，长按画面打开播放设置，长按两侧倍速播放；横屏视频自动全屏，支持双指/半屏亮度与音量调节 |
| 平板端 | 横屏同桌面端布局，竖屏同手机端布局，全屏期间锁定横屏 |
| 电视端（Android TV） | 遥控器焦点导航，左右键快退/快进 10 秒，返回键逐级收起面板与退出 |

所有端均支持：下一集后台预缓冲、倍速/清晰度/弹幕开关记忆、在线弹幕屏蔽词与显示区域自定义。

### 网盘分享与 TVBox 订阅

- **夸克网盘分享直链播放**：
  - 在 **设置 › 网盘分享** 使用夸克 App 扫码登录（仅保存本地 Cookie，不上传任何服务器）。
  - 粘贴 `https://pan.quark.cn/s/xxxx` 分享链接即可免转存解析剧集列表；播放时自动将当前集转存至网盘根目录 `gomovie_tmp`，播完可在设置页一键清理临时目录。
- **饭太硬 / TVBox 订阅源**：
  - 在 **设置 › 网盘分享** 填入饭太硬或标准 TVBox JSON 配置地址并点击「同步订阅」，即可自动解析其中的 CMS / T4 站点与网盘资源（自动剥离 `//`、`/* */` 注释及 `**Base64` 编码）。
  - 同步后的订阅站点会直接出现在发现页站源列表中，并持久化保存在本地，支持随时清除。

### 追剧、下载与多用户

- **追剧与观看记录**：后台每 30 分钟自动检查未完结追剧更新；观看记录按今天 / 昨天 / 更早分组，支持搜索、按站源筛选与批量删除。
- **离线下载**：支持选集多选下载并自动封装为标准 `.mp4`（`下载目录/剧名/第 N 集.mp4`），Android 支持导出至系统 `Movies` 目录（电视端不提供下载）。
- **多用户与备份**：支持多用户独立保存追剧、记录与搜索，管理员可配置密码、可用站源与下载权限；支持一键导出/恢复完整配置备份。

## 安装

在 [Releases](../../releases) 下载对应平台的安装包（文件名以 `gomovie-` 开头）：

| 平台 | 安装说明 |
| --- | --- |
| Android 7.0+ | 提供 `arm64-v8a` / `armeabi-v7a` / `x86_64` APK（主流手机选 `arm64-v8a`）；同签名可覆盖升级 |
| Windows 10/11 x64 | `*-setup.exe` 安装包（默认当前用户安装，无需管理员权限）或便携版 ZIP（数据保存在程序旁 `userdata` 目录） |
| iOS 15.1+ | 未签名 IPA，需使用个人签名工具侧载 |
| macOS 12+ | Apple Silicon + Intel 通用 DMG，拖入「应用程序」后首次打开需解除隔离（见下方提示） |

> [!IMPORTANT]
> macOS 首次打开前请在终端执行：
> ```sh
> xattr -dr com.apple.quarantine /Applications/GoMovie.app
> ```

### 站源可用性说明

- **爱看机器人、韩小圈**：播放源限制中国大陆网络，海外 IP 可能出现 403 或超时。
- **青空**：需在 **设置 › 站源 › 站源账号** 登录后使用。
- **MissAV**：站点开启了 Cloudflare 人机验证，应用内如无法通过请按提示在浏览器中访问。
- **夸克网盘分享**：剧集列表免登录解析，获取播放直链需先在 **设置 › 网盘分享** 扫码登录。

## 使用说明

1. **首次启动**：阅读并同意使用条款后进入主界面，默认管理员账号无密码。
2. **站源管理**：内置 14 个站源模块随包自动安装；在 **我的 › 模块** 可开关、更新、卸载或从本地 `.zip` / URL 安装模块。
3. **订阅与网盘**：在 **设置 › 网盘分享** 绑定夸克账号或同步饭太硬/TVBox 订阅；在发现页顶部点击「粘贴网盘链接」可直接播放分享链接。
4. **问题排查**：遇播放异常可在 **设置 › 播放 › 解码方式** 切换兼容模式，或在 **设置 › 代理** 配置直连/HTTP/HTTPS/SOCKS5 代理；反馈问题请附带 **设置 › 诊断 › 播放调试日记**。
